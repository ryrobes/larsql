# HTMX Server-Side Rendering Pattern

This kit uses **HTMX** with server-side rendered HTML. There is NO separate frontend - everything is generated by Python functions in `app.py`.

## File Structure

```
kit/
└── app.py    # EVERYTHING: FastAPI backend + HTML generation
```

That's it. One file. All UI is rendered server-side as HTML strings.

## Key Concepts

1. **No frontend files** - HTML is generated by Python functions
2. **No React/JS state** - Server holds state, HTMX swaps HTML fragments
3. **No imports to wire up** - Just add Python functions
4. **Hot reload works** - Change app.py, refresh browser

## How HTMX Works

```html
<!-- Filter triggers re-fetch of dashboard fragment -->
<select hx-get="/dashboard" hx-target="#dashboard" hx-trigger="change">
    <option>All</option>
    <option>Category A</option>
</select>

<!-- Server returns HTML, HTMX swaps it into #dashboard -->
<div id="dashboard">
    <!-- This gets replaced with server response -->
</div>
```

## Adding New UI Components

### 1. Create a Python function that returns HTML

```python
def my_component(title: str, data: list) -> str:
    """Render my custom component."""
    rows_html = ''.join(f'<li>{item}</li>' for item in data)
    return f'''
    <div class="card">
        <h3 class="text-lg font-semibold mb-3">{title}</h3>
        <ul>{rows_html}</ul>
    </div>
    '''
```

### 2. Use it in the dashboard

```python
async def get_dashboard_content(...) -> str:
    # Fetch data
    with get_connection() as conn:
        my_data = query_to_list(conn, "SELECT name FROM items")

    return f'''
    <div class="space-y-6">
        {my_component("My Items", [row['name'] for row in my_data])}
        <!-- other components -->
    </div>
    '''
```

## Built-in Helper Functions

The template includes these HTML generators:

- `base_page(title, content)` - Full HTML page wrapper
- `layout(title, subtitle, filters_html, content)` - Page layout with header
- `filter_dropdown(name, label, options, value)` - Dropdown filter
- `filter_month(name, label, value)` - Month picker
- `filter_search(name, label, value)` - Search input
- `kpi_card(title, value, fmt)` - KPI metric card
- `chart_card(title, chart_id, chart_type, data, x_key, y_keys)` - Chart.js chart
- `data_table(title, columns, rows)` - Data table

## Adding New Endpoints

### Data endpoint (returns JSON)

```python
@app.get("/api/my-data")
async def get_my_data(category: Optional[str] = None):
    with get_connection() as conn:
        sql = "SELECT * FROM my_table"
        if category:
            sql += f" WHERE category = '{category}'"
        return {"data": query_to_list(conn, sql)}
```

### Fragment endpoint (returns HTML for HTMX)

```python
@app.get("/components/my-section", response_class=HTMLResponse)
async def get_my_section(filter: Optional[str] = None):
    """Returns HTML fragment that HTMX swaps in."""
    with get_connection() as conn:
        data = query_to_list(conn, "SELECT * FROM items")
    return my_component("Items", data)
```

## HTMX Patterns

### Auto-refresh on filter change

```python
def filter_dropdown(name, label, options, value):
    return f'''
    <select name="{name}" class="input"
            hx-get="/dashboard"
            hx-target="#dashboard"
            hx-trigger="change">
        <option value="">All</option>
        {options_html}
    </select>
    '''
```

### Load on scroll (infinite scroll)

```html
<div hx-get="/api/more-items?page=2"
     hx-trigger="revealed"
     hx-swap="afterend">
    Loading more...
</div>
```

### Debounced search

```python
def filter_search(name, label, value):
    return f'''
    <input type="text" name="{name}" class="input"
           hx-get="/dashboard"
           hx-target="#dashboard"
           hx-trigger="keyup changed delay:300ms">
    '''
```

## Chart.js Integration

Charts are rendered with inline JavaScript:

```python
def chart_card(title, chart_id, chart_type, data, x_key, y_keys):
    # Build chart config
    config = {
        'type': chart_type,
        'data': {...},
        'options': {...}
    }
    return f'''
    <div class="card">
        <h3>{title}</h3>
        <canvas id="{chart_id}"></canvas>
        <script>
            new Chart(document.getElementById('{chart_id}'), {json.dumps(config)});
        </script>
    </div>
    '''
```
