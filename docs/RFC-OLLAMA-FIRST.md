# RFC: Unified Provider & Model Tier Configuration

**Status:** Approved  
**Author:** Calliope + Ryan  
**Date:** 2026-02-05

## Summary

Replace scattered environment variables with a unified `models.yaml` configuration. Allow users to configure multiple providers (OpenRouter + Ollama) during bootstrap, then assign models from any provider to semantic tiers that cascades reference via Jinja templating.

## Goals

1. **No hard provider requirement** - Users can run 100% Ollama, 100% OpenRouter, or mix both
2. **Single source of truth** - `models.yaml` replaces scattered `LARS_*_MODEL` env vars
3. **Tier-based model references** - Cascades use `{{ models.fast }}` not `google/gemini-3-flash`
4. **Unified bootstrap UX** - Configure all providers in one flow, assign tiers from combined pool

## Design

### 1. Model Tiers

| Tier | Purpose | Typical Use |
|------|---------|-------------|
| `embedding` | Vector embeddings | RAG, SIMILAR_TO, EMBED(), schema search |
| `fast` | Quick, cheap, high-volume | MEANS, CLASSIFY, parsing, simple filters |
| `standard` | Balanced quality/cost | Default for most operators |
| `quality` | Complex analysis | SUMMARIZE, ANALYZE, multi-step reasoning |
| `flagship` | Best available | Critical decisions, ask_data, complex agents |

### 3. Configuration File: models.yaml

```yaml
# ~/.lars/models.yaml
# Generated by: lars bootstrap
# Customize freely - cascade Jinja templates reference these tiers

providers:
  openrouter:
    enabled: true
    api_key_env: OPENROUTER_API_KEY  # Reference to env var, not the value
    
  ollama:
    enabled: true
    hosts:
      default: http://localhost:11434
      gpu-server: http://10.0.0.50:11434

models:
  # Tier assignments - can be any model from any configured provider
  embedding: qwen/qwen3-embedding-8b
  fast: google/gemini-2.5-flash-lite
  standard: google/gemini-3-flash-preview  
  quality: anthropic/claude-sonnet-4
  flagship: anthropic/claude-opus-4

# Optional: capability requirements (validated at startup)
capabilities:
  flagship:
    - reasoning  # Warns if model doesn't support extended thinking
```

### 5. Cascade Jinja Templating

**Before (hardcoded):**
```yaml
cells:
  - name: evaluate
    model: google/gemini-3-flash-preview
    instructions: |
      Does this text match?
```

**After (tier reference):**
```yaml
cells:
  - name: evaluate
    model: "{{ models.fast }}"
    instructions: |
      Does this text match?
```

**Complex cascade with multiple tiers:**
```yaml
cells:
  - name: parse
    model: "{{ models.fast }}"        # Cheap model for parsing
    instructions: Extract the key fields...
    
  - name: analyze  
    model: "{{ models.quality }}"     # Better model for analysis
    instructions: Analyze the implications...
    
  - name: evaluate
    model: "{{ models.flagship }}"    # Best model for final decision
    evaluator_model: "{{ models.quality }}"
    instructions: Make the final determination...
```

**Escape hatch (literal model):**
```yaml
cells:
  - name: special_case
    model: anthropic/claude-opus-4    # Explicit override, ignores tiers
```

### 6. Environment Variable Deprecation

| Old (Deprecated) | New (models.yaml) |
|------------------|-------------------|
| `LARS_DEFAULT_MODEL` | `models.standard` |
| `LARS_DEFAULT_EMBED_MODEL` | `models.embedding` |
| `LARS_EVAL_MODEL` | `models.quality` |
| `LARS_OLLAMA_HOSTS` | `providers.ollama.hosts` |
| `LARS_OLLAMA_ENABLED` | `providers.ollama.enabled` |

**Migration behavior:**
1. If `models.yaml` exists → use it exclusively
2. Else if legacy env vars exist → use them with deprecation warning
3. Else → use hardcoded defaults (OpenRouter models)

### 7. Fallback Defaults

When no configuration exists:

```python
DEFAULT_MODELS = {
    "embedding": "qwen/qwen3-embedding-8b",
    "fast": "google/gemini-2.5-flash-lite",
    "standard": "google/gemini-3-flash-preview",
    "quality": "anthropic/claude-sonnet-4",
    "flagship": "anthropic/claude-opus-4",
}
```

These require OpenRouter, which is why bootstrap prompts for configuration.

### 8. Model Resolution in Runner

```python
def resolve_model(model_spec: str, models_config: dict) -> str:
    """
    Resolve a model specification to an actual model ID.
    
    Args:
        model_spec: Either a Jinja template like "{{ models.fast }}" 
                    or a literal model ID like "ollama/mistral:7b"
        models_config: The loaded models.yaml config
    
    Returns:
        Resolved model ID (e.g., "google/gemini-3-flash-preview")
    """
    # Check if it's a Jinja template
    if "{{" in model_spec and "}}" in model_spec:
        # Extract tier: "{{ models.fast }}" -> "fast"
        match = re.search(r'\{\{\s*models\.(\w+)\s*\}\}', model_spec)
        if match:
            tier = match.group(1)
            resolved = models_config.get("models", {}).get(tier)
            if resolved:
                return resolved
            # Fallback to defaults
            return DEFAULT_MODELS.get(tier, model_spec)
    
    # Literal model ID - return as-is
    return model_spec
```

### 9. Provider Detection & Routing

The system already handles provider routing via model ID prefixes:
- `ollama/model` → Route to Ollama
- `ollama@alias/model` → Route to specific Ollama host
- `openrouter/model` or unprefixed → Route to OpenRouter

No changes needed here - just ensure `models.yaml` stores full model IDs with prefixes.
